Deploying Panchmukhi Job Card Pro

Host on GitHub Pages with Cloud Firestore persistence

  1. Create a public repository on GitHub named jobcard-app.
  2. Upload this single file as index.html to the root directory.
  3. Navigate to Settings → Pages → Source: Deploy from main branch.
  4. Your app is live with automatic offline persistence and Cloud Firestore sync!
